Project 11: Haunted House

For our haunted exhibit, we built two interactive pieces using SPIKE Prime. The first was a drop scare that winds an object up on a string and then drops it suddenly. We first designed a clutch that let the spool spin freely so the object would fall straight away, but the clutch couldn’t hold enough weight. We switched to a trap door instead, but that didn’t work reliably either: the string was too light to pull through and drop cleanly, or it had too much friction to run smoothly. The second piece was a carnival-style game where players throw a ping-pong ball at a skull. A hit wirelessly sends a message from one hub to another, which triggers a dropper to release a piece of candy that slides down and comes out of the skull’s mouth.
